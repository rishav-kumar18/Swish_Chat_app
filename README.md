💬 Swish – Real Time Chat

📖 Overview

A real-time chat web application that enables instant communication between users.  
It supports live messaging, modern UI, and scalable backend services for seamless interaction.

🚀 Features

User Authentication: Secure login and registration system  
Real-Time Messaging: Instant updates using Socket.IO  
Chat Rooms: Create or join chat rooms dynamically  
Responsive Design: Optimized for both desktop and mobile devices  
Scalable Architecture: Separate backend and frontend for easy deployment and maintenance  

🛠️ Tech Stack

Frontend: React, HTML, CSS, JavaScript  
Backend: Node.js, Express.js, Socket.IO  
Database: MongoDB 
Server: Node.js / Render
